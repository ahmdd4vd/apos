REPOSITORY DETECTION

Two starting points.
One proportional workflow.

Empty project

Do not invent requirements. Clarify intent, create minimum state, and define the first implementation slice.

  • Goal
  • Bootstrap task
  • Known unknowns

Existing project

Observe first. Record facts, unknowns, and adoption work without rewriting the project’s history.

  • Repository scan
  • Adoption task
  • Evidence-based architecture
